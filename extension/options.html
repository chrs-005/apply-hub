⚡ Apply Hub Autofill

Fill this in once. The extension uses it to complete applications in seconds. Everything stays in this browser (chrome.storage); nothing is uploaded except tracker entries, and only if you set up sync below.

📎 Documents (attached automatically)

PDF recommended. When a form has a “Resume/CV”, “Cover letter” or “Transcript” upload, the matching file is attached.

💬 Answer bank

Long questions (“Why do you want to work at …?”) are matched to these and filled in. Use {company} and {role}; they're replaced automatically.
Fastest way to grow it: after you write a good answer on any site, right-click inside the box → Save this answer to Apply Hub.

✨ Claude (optional: answers what the profile doesn't cover)

With an API key, fields Apply Hub doesn't recognise are sent to Claude together with your profile, saved answers, CV and the page text. Claude answers what it can from your data (purple outline) and lists everything else in a “needs you” panel. Long essay boxes get a ✍️ Draft with Claude button instead of being auto-written.
Uses your own Anthropic API key (from console.anthropic.com, separate from a Claude.ai subscription, billed per use). The key stays in this browser.

🔄 Tracker sync (optional)

Paste the same GitHub token + Gist ID you use in the Apply Hub app. “Add to tracker” in the popup then shows up on your phone.
